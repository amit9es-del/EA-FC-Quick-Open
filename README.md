# EA FC Quick Open

A lightweight userscript for the EA SPORTS FC Ultimate Team Web App that adds:

**Open | Quick Open**

The `Quick Open` option skips the pack-opening animation and continues directly to the pack result screen.

## Features

- Adds a separate **Quick Open** option next to the normal **Open** button.
- Keeps the original EA `Open` behavior intact.
- Skips the visual pack animation when using `Quick Open`.
- Includes a press/touch effect so the button feels responsive.
- Designed to work with Safari + Userscripts on iPhone.
- No password storage.
- No EA login credentials are collected.

## Installation on iPhone

1. Install the **Userscripts** Safari extension.
2. Enable Userscripts in:
   `Settings → Apps → Safari → Extensions → Userscripts`
3. Make sure Userscripts has permission to run on `ea.com`.
4. Open this file:
   `FC-QuickOpen-Final.user.js`
5. Install/save it with Userscripts.
6. Close all EA Web App tabs.
7. Reopen the EA FC Ultimate Team Web App.
8. Go to:
   `Store → My Packs`

You should now see:

**Open | Quick Open**

## Usage

- Tap **Open** to open a pack normally with EA's standard animation.
- Tap **Quick Open** to open the same pack while skipping the pack animation.

## Compatibility

Currently tested with:

- EA SPORTS FC Ultimate Team Web App
- Safari on iPhone
- Userscripts for Safari

Because EA can update the Web App at any time, future EA updates may temporarily break the script.
